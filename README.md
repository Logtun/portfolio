## Deploy on Vercel

1. Log in at [vercel.com](https://vercel.com) with your GitHub account.
2. Click **Add New → Project**.
3. Find **portfolio** in the GitHub list and click **Import**.
4. Leave every setting as it is (Framework Preset: Other, no build command) and click **Deploy**.

The social preview tags (`og:url`, `og:image`, `twitter:image`, `canonical`) in `index.html` point to `https://iamlogtun-portfolio.vercel.app/`. If the project's address changes, replace that URL in `index.html` (search for `iamlogtun-portfolio.vercel.app`) and commit; Vercel redeploys on every push.
